# Slideshow App

ローカルWi-Fi環境（インターネット接続不要）で、PC内の写真を参加者のスマホに
リアルタイム配信・同期表示するシンプルなスライドショーWebアプリです。

Python標準ライブラリのみで動作するため、外部ライブラリのインストールは不要です。

## 機能

- 全端末で同じタイミングに画像が切り替わる同期スライドショー
- サイドバーのショーケースから任意の画像へ直接ジャンプ
- 自動再生の開始/停止を切り替え
- 現在表示中の画像のフォルダパス表示
- `photos` フォルダの階層構造を再帰的に探索

## ファイル構成

```
slideshow_app/
├── server.py     # サーバー（Python標準ライブラリのみ）
├── index.html    # フロントエンド（単一ファイル）
└── photos/       # 写真フォルダ（任意の階層構造で配置）
```

## 実行方法

1. `photos` フォルダに画像（`.jpg`, `.jpeg`, `.png`）を配置する
   （サブフォルダでの階層化管理も可能）

2. `server.py` を実行する

   ```bash
   python server.py
   ```

3. PCと同じWi-Fiに接続したスマホのブラウザから、
   `http://<PCのIPアドレス>:8000` を入力してアクセスする
   （`http://` でのアクセスが必要です）

## 使い方

- デフォルトで10秒ごとに自動で次の画像へ進みます
- 左上のメニューボタンでサイドバーを開き、
  - 写真一覧（ショーケース）から任意の画像を選択
  - 自動再生の開始/停止を切り替え
